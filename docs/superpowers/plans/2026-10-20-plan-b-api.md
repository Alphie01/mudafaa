- `apps/api` NestJS 12 (ESM). Modüller: `auth`, `users`, `ranks`, `content` (eşleyici, sürüm, yayın, varlık), `cases` (katalog + CaseLoader), `game-sessions`, `admin`, `content-validation` (BullMQ), `health`. Ortak katman `src/common`.
- Oyun mantığının tamamı `@mudafaa/engine`'dedir. API yalnızca kimlik, kalıcılık, transaction, idempotency ve ilerlemeyle ilgilenir.

- API↔istemci DTO şemaları `packages/case-schema/src/api.ts`'tedir (Zod). Hem API testleri hem Flutter sözleşme fikstürleri bu şemaları kullanır.
